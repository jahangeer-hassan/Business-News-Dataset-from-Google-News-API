# 📰 Business News Dataset Analysis using Google News API

## 📌 Project Overview

This project focuses on collecting and analyzing **Business News data** using the **Google News API**. The main objective of this project is to perform **Exploratory Data Analysis (EDA)** on real-world business news articles to identify trends, patterns, popular topics, news sources, publishing activity, and sentiment-related insights.

The project demonstrates how data analytics and visualization techniques can transform raw news data into meaningful business intelligence insights.

---

# 🎯 Objectives

* Collect business news using Google News API
* Analyze trending business topics
* Explore publishing patterns and news frequency
* Identify top news sources and categories
* Perform text-based exploratory analysis
* Visualize news trends using charts and graphs
* Generate meaningful business insights from news data
